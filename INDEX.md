- `stage1_extract()` — Feature extraction
- `stage2_interpret()` — Price interpretation

**[predictor.py](predictor.py)** — ML inference

## 🚀 Quick Command Reference

```bash
# Setup
cp .env.template .env
# Edit .env with GEMINI_API_KEY
pip install -r requirements.txt

# Training
jupyter notebook ml_pipeline.ipynb
# Run all cells

# Development
# Terminal 1:
uvicorn main:app --host 0.0.0.0 --port 8000

# Terminal 2:
streamlit run streamlit_app.py

# Docker
docker build -t real-estate-agent:v1 .
docker run -p 8000:8000 --env-file .env real-estate-agent:v1

# Testing
curl http://localhost:8000/health
```
