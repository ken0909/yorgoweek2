CRITICAL POINTS:

1. FIELD NAMES (must match everywhere):
   - schemas.py: HouseFeatures class
   - predictor.py: FEATURE_COLUMNS list
   - prompts.py: JSON keys in Stage 1 prompt
   - ml_pipeline.ipynb: FEATURE_NAMES list

2. DATA LEAKAGE:
   - Transformers fit on X_train ONLY
   - Applied to X_val and X_test
   - FALLBACKS from training set statistics

3. ERROR HANDLING:
   - Try/except on all Gemini calls
   - Try/except on all ML predictions
   - Return degraded responses, never crash

4. DEPLOYMENT:
   - Docker: Build from Dockerfile
   - Environment: .env file with GEMINI_API_KEY
   - ML Model: Generated by ml_pipeline.ipynb Section 7
